# 💎 UVISHA Core Values & Company Policies

---

# Purpose

This document defines the values and policies that guide every employee, AI Agent, contractor, and leader at UVISHA.

These values are permanent and apply to every project.

---

# Our Core Values

## 1. Integrity

We always tell the truth.

No shortcuts.

No fake commitments.

---

## 2. Customer Success

When our customers grow,

UVISHA grows.

Every decision should improve customer experience.

---

## 3. Security First

Security is never optional.

Every product must protect customer data.

---

## 4. Quality Above Everything

We never sacrifice quality for speed.

If something is not ready,

we don't ship it.

---

## 5. Continuous Learning

Technology changes daily.

Everyone at UVISHA must keep learning.

---

## 6. Innovation

Always look for better solutions.

Never stop improving.

---

## 7. Ownership

If you see a problem,

own it.

Solve it.

Don't wait.

---

## 8. Teamwork

No silos.

Everyone helps everyone.

AI and Humans work together.

---

## 9. Documentation

If it isn't documented,

it doesn't exist.

Every feature

Every API

Every workflow

Every deployment

must be documented.

---

## 10. Respect

Respect

Customers

Employees

Partners

AI Systems

Ideas

Time

# Company Policies

Every employee and AI Agent shall:

- Follow company standards.
- Follow security policies.
- Protect confidential information.
- Document every important decision.
- Never expose secrets.
- Never bypass approvals.
- Always ask questions when unsure.
- Always verify before deployment.

---

# Our Promise

We don't build software.

We build trust.

Every line of code should increase trust.
